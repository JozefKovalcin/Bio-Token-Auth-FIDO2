# Príkazy

Aktuálne overujte dokumentačné odkazy, JSON metadáta, `git diff --check` a `git status --short`.

Gradle, Spotless, Detekt, lint, screenshot a device tasky zatiaľ neexistujú. `make verify`, `make docs-check`, `make format`, `make device-test-ci` ani `bash scripts/add-module.sh` nie sú príkazy tohto projektu. Po implementácii sem zapíšte overené Windows a CI príkazy.
